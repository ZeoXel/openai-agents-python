# 研究机器人

这是一个简单的多智能体研究机器人示例。运行方式如下:

```bash
python -m examples.research_bot.main
```

## 架构

流程如下:

1. 用户输入他们的研究主题
2. `planner_agent` 制定一个在网络上搜索信息的计划。该计划是一个搜索查询列表,每个查询包含搜索词和查询原因。
3. 对于每个搜索项,我们运行一个 `search_agent`,它使用网络搜索工具来搜索该术语并总结结果。这些搜索全部并行运行。
4. 最后,`writer_agent` 接收搜索摘要,并创建一份书面报告。

## 改进建议

如果你正在构建自己的研究机器人,可以考虑添加以下功能:

1. 检索: 添加从向量存储中获取相关信息的支持。你可以使用文件搜索工具来实现。
2. 图片和文件上传: 允许用户附加 PDF 或其他文件,作为研究的基础上下文。
3. 更多规划和思考: 模型在有更多思考时间的情况下通常会产生更好的结果。改进规划过程以制定更好的计划,并添加评估步骤,使模型可以选择改进其结果、搜索更多内容等。
4. 代码执行: 允许运行代码,这对数据分析很有用。
